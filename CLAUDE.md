# knowledge-retriever — Project Instructions

## On every new session: read context first

Before doing anything else, read `system/project-context.md` and
`system/session-log.md` (most recent entry only).

Use these to orient yourself:
- What the project is and what the goal is
- Where we are now (current phase, what's working, what's not)
- What was decided last session and what comes next

Then greet the user with a one-paragraph summary:
- Current status of the project
- What the recommended next step is
- One open question from the last session log if relevant

Do not ask the user to explain the project. Do not ask what they want to work
on before giving this summary. Lead with context, then ask how they want to proceed.
