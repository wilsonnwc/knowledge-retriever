# Projects

Registry of projects a note's `projects:` frontmatter field can reference. Managed via `scripts/chat.py --new-project <name>` and `--archive-project <name>` — do not hand-edit the status field, but feel free to read this to see what's active.

Archiving a project only changes its status here; it never removes the project label from notes that carry it (see `system/taxonomy.md`).
