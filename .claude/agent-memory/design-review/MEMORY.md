# Accepted design decisions (knowledge-retriever)

Decisions the product owner made explicitly. The design review passes these to every agent and never re-flags them.

- WCAG colour-contrast findings on the accent orange (rank numbers, Build toggle, sidebar, Save build idea) and on faded "done" cards are not a priority — a personal app; reviews should focus on usability and readability instead (2026-10-05)
- Developer-style error messages and no "Try again" button on load failures are acceptable — single technical user, a page reload recovers (2026-10-05)
- Small tap height on single-line "Everything else" titles is acceptable (2026-10-05)
- The local app opening on Search (not Today) is fine — the hosted site opens on Today (2026-10-05)
- Reader keeps the email's leading title repeats and podcast-player links as-is for now (2026-10-05)
- Search landing page and desktop sidebar contrast (hint text, Import tab, "+ New", active nav item) are not a priority (2026-10-05)
